Services / Migration

Confluence and Wiki Migration to AsciiDoc or Markdown

The advantage of docs-as-code, as opposed to existing wiki software (Confluence, Notion, etc.), is the ability to migrate and adapt it easily. Additionally, wikis can become stuffed with out-of-date documentation, all in a limited format. I offer both the mass conversion and the critical editing and auditing involved. I will help guide the decision-making process, and enable you to clean up docs in real time.

How a migration runs

  • Inventory and audit of existing documentation.
  • Agree on what can be kept, merged, and archived.
  • Mass-convert the agreed pages to the target format (AsciiDoc, Markdown, etc.). Manually review after the process.
  • Clean up the infrastructure, ensuring the websites and links all still match.
  • Implement CI/CD pipeline for future updates and additions.

Why Migrate?

Using CI/CD docs-as-code documentation makes it easy to version to specific releases. It enables product and documentation to update together. The documentation system can also fit effortlessly into existing engineering and update processes.
