Docs-as-Code CI/CD Publishing Pipelines

Docs-as-Code enables a self-publishing documentation pipeline. Documentation stays updated this way, all through code merges and Git pushes.

The Advantages

  • Merge or pull requests will update documentation automatically.
  • Staging and review processes are built into the process, and a preview site can be included in the pipeline.
  • Site is easily personalised to the client, through stylesheets and UI updates.
  • Different CI/CD pipelines can update different release versions and patches.

Platforms

I am experienced and confident with the inbuilt CI/CD tools of all the major repositories. This means I can fit my process into your system whether you use GitHub, GitLab, or Bitbucket.
