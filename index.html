Services

01

Technical writing

Everything is covered; general user manuals, guides for installation and upgrading of software, user facing tutorials, release notes, API reference pages, and internal documentation from style guides to onboaridng materials. I work directly with engineering teams, to ensure accuracy and fit my documentation pipelines into the existing build chain.

02

Static Documentation Sites Toolchains

Using the documentation site generator tools Antora and Docusaurus, I'm able to create multi-version sites, fitting the client's brand identity. Throug this, I can also implement a fast, simple, and easily navigated site, which is cheap to host due to its docs-as-code nature.

03

Docs-as-code pipelines

I also construct the CI/CD pipelines for documentation, creating automated site build chains which update on git push or merge. I can also set up preview sites for the sake of review and editing. I can achieve this with the inbuilt CI/CD tools from Github, Gitlab, and Bitbucket.

04

Documentation migration and Audit

I am also familiar with migrating from Confluence, Word or other systems into AsciiDoc or Markdown, for use with the site generators. I can audit and review documentation as I go, analysing weaknesses, identifying missing information, and setting documentation priority updates.
